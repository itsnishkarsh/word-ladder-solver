# Word Ladder Puzzle Solver 🪜

A desktop application built in Java that solves Lewis Carroll's classic "Word Ladder" puzzle. It uses a Breadth-First Search (BFS) algorithm to find the absolute shortest path between two words, changing only one letter at a time.

## 🚀 Features

*   **Optimal Pathfinding:** Uses an optimized BFS algorithm with a parent-map structure to guarantee the shortest possible ladder.
*   **Custom Visualization:** A unique, auto-scrolling visual ladder UI built entirely from scratch using Java 2D Graphics.
*   **Live Analytics Dashboard:** Tracks and displays algorithmic performance, including total words explored and search duration in milliseconds.
*   **Massive Dictionary:** Capable of processing a comprehensive English dictionary (280,000+ words) in $O(1)$ lookup time using a HashSet.

## 🛠️ Tech Stack

*   **Language:** Java
*   **GUI Framework:** Java Swing / AWT
*   **Data Structures:** Queues, HashSets, HashMaps
